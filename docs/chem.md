# 化学クイズ

高校化学（化学基礎・化学）を、3つの形式（と、それをまぜた**ミックス**）で遊ぶ。ひとり（CPUと対戦）と、友達対戦（2〜4人）。学年は**高校**と**高校（大学入試）**だけ。問題は早押し約690・資料選択約600（うち図の問題が約60）・計算128テンプレート（毎回数字が変わる）。

| 形式 | 内容 | 判定 |
|---|---|---|
| ⚡ 早押し | 問題文が1文字ずつ流れる。わかったら押して、かな・化学式（H₂SO₄ など）・数字で答える | 読みの辞書・化学式の一覧 → 合わなければ AI |
| 🖼️ 資料選択 | 表・グラフ（滴定曲線・溶解度曲線・エネルギー図・状態図・冷却曲線・イオン化エネルギー・気体の法則）・構造式・周期表を見て、4択で答える | 選択肢の一致 |
| 🧮 計算 | 数字の変わる計算問題（モル・濃度・pH・熱化学・電気分解・平衡・有機の元素分析など）。**全員が同時に答え、答え合わせで一斉に開示**。速いほど高得点。答え合わせに途中式の解説 | 許容誤差・有効数字 |
| 🎲 ミックス | 上の3つがまざって出る。選んだ単元に問題のない形式は出ない | 出た形式のとおり |

設定: 形式 / **学年**（高校 / 高校（大学入試））/ **単元** / 難しさ（やさしい・ふつう・むずかしい）/ 問題数（5・10・15・**30**）/ CPUの人数（0〜3）。

## 単元の選びかた
教科書の順に24単元（化学基礎7 → 理論化学8 → 無機4 → 有機3 → 高分子2）。

1. 物質の構成と分離 2. 原子の構造と周期表 3. 化学結合と結晶 4. 物質量と濃度 5. 化学反応式と量的関係 6. 酸と塩基・中和 7. 酸化還元 8. 気体 9. 熱化学 10. 溶液と希薄溶液 11. 結晶格子と状態変化 12. 電池 13. 電気分解 14. 反応速度 15. 化学平衡と電離平衡 16. 非金属元素 17. 典型金属元素 18. 遷移元素と金属イオン 19. 無機化学工業 20. 脂肪族化合物 21. 芳香族化合物 22. 構造決定・異性体 23. 天然高分子（糖・アミノ酸・タンパク質・核酸） 24. 合成高分子

- **はじめ〜おわり**: 2つの単元をタップすると、その間をまとめて選ぶ（「電池〜化学平衡と電離平衡」）。
- **ひとつずつ**: 「1つずつ」に切りかえると、タップした単元だけを足し引きできる。
- **まとめて**: すべて / 化学基礎 / 理論化学 / 無機 / 有機 / 高分子 / 電池と電気分解 / 酸塩基と酸化還元 / 有機＋高分子。
- 全部選ぶと「すべての単元」になる。どの形式にも、全24単元・全レベルに15問以上ある（`tests/chem.test.js`）。

## 学年と難しさ
- **高校**: 問題のレベル（1=基礎 / 2=標準 / 3=発展）で出やすさを変える。大学入試だけの問題（`xo`）は出ない。
- **高校（大学入試）**: 共通テスト・二次レベル。問題には `ex`（1=基礎 / 2=標準 / 3=発展）が付き、`ex` のある問題だけを出す。制限時間は約1.3倍（資料選択は最低25秒）。過去問の文章は使わず、すべてオリジナル。
- 難しさ（やさしい・ふつう・むずかしい）は、レベル（または `ex`）の出やすさの重みを変える。

## ルール
- 1ラウンド = 1問。点数は「正解 10点 + 早さのボーナス」。最後に一番高い人の勝ち（同点は同点1位）。
- **資料選択・計算**: 全員が同時に答える。全員が答え終わるか制限時間で締め切り、**一斉に開示**して採点する。計算は、答え合わせで途中式（解説）を見せる。
- **早押し**: 問題文が流れる。押すと文が止まり（全員の画面で同じ位置）、押した人だけが12秒以内に答える。早く押すほど高得点（10点 + 最大10点）。まちがい・時間切れは **-5点** でその問題の解答権を失い、文はつづきから流れる。全員まちがえるか、文が終わって6秒たつと答えを開示する。化学式は **[[H2SO4]]** のように、ひとつの単位として流れる（途中で切れない）。
- 計算の採点: 許容誤差（相対または絶対）の中、または、**有効数字で丸めた値と一致**すれば正解。入力は `1.5` `-0.3` `1.2e3` `6.0×10^23` `3/4` が使える（専用の数字キーボードつき）。

## 答えの入力
- **早押し**: キーボードの「かな」「式・英数」で切りかえる。「式・英数」は元素記号（H C N O S P F Cl Br I Na K Ca Mg Al Fe Cu Zn Ag Pb Mn）・A-Z・a-z・数字・`+` `−` `(` `)` `=`。パソコンの物理キーボードでも打てる。
- 用語は読み（ひらがな・カタカナ・空白・記号の違いは無視）、化学式は**大文字小文字を区別**（CO と Co は別）。下つき文字（H₂SO₄）・全角・空白・中点は、そろえて比べる。答えの表示そのものも正解として扱う。

## AI による答えの確認（早押しだけ）
- 辞書で決まらなかった答えだけ、中継 Worker の `POST /chem/judge`（`worker/chem-judge.mjs`）で Gemini に「正解と同じ物質・用語を指しているか」を厳しく判定させる。
- 通すもの: 名前と化学式のどちらで答えても同じもの、別名・通称、カタカナ/漢字の表記ゆれ。断るもの: 似た物質、ちがう価数やイオン、大文字小文字でちがう元素記号（Co と CO）、あいまいな答え。入力は「データ」として扱い、中に指示があっても無視させる。
- 同じ（正解, 入力）の結果は KV に半年キャッシュ（キーは `chem1:`。化学式は大文字小文字を区別して覚える）。端末にも覚える（`js/games/chem/judge.js`）。
- 判定できないとき（無料枠の上限・通信エラー）は不正解になり、「AIで確認できなかったよ」と出す。CPUの答えは AI に聞かない。
- 地理クイズ・しりとりと同じ `GEMINI_API_KEY` / `GEMINI_MODEL` / `CACHE` を使う（`docs/gemini-worker-setup.md`）。

## 問題の内容（元データは `tools/chem-source/`）
| 形式 | 元のファイル | 数 |
|---|---|---|
| 早押し | `buzz-u01-u04.txt` … `buzz-u21-u24.txt`・`buzz-extra.txt`・`buzz-seed.txt` | 691（高校のレベル 1:212 / 2:312 / 3:167、大学入試 `ex` 1:281 / 2:263 / 3:110） |
| 資料選択 | `choice-u01-u04.txt` … `choice-u21-u24.txt`・`choice-diagrams.txt`・`choice-seed.txt` | 605（高校のレベル 1:151 / 2:218 / 3:173、大学入試 `ex` 1:152 / 2:275 / 3:102。大学入試だけ 63・図の問題 61） |
| 計算 | `js/games/chem/calc.js` のテンプレート | 128（大学入試だけ 14） |

- **書式（早押し）**: `id|単元|レベル1〜3|大学入試|問題文|答えの表示|読み(,区切り)|化学式(,区切り・省略可)`。大学入試の欄は 0=高校だけ / 1〜3=高校にも大学入試にも（基礎・標準・発展）/ `x1`〜`x3`=大学入試だけ。問題文は「？」か「。」で終わる。化学式は `[[H2SO4]]` `[[Cu^2+]]` `[[SO4^2-]]` `[[[Cu(NH3)4]^2+]]` のように書くと、添え字・電荷つきで表示される。
- **書式（資料選択）**: `id|単元|レベル|大学入試|問題文|正解|まちがい1|まちがい2|まちがい3|資料(JSON・省略可)`。資料は `{"k":"table",…}` のほか、`{"gen":"titration","kind":"wa-sb"}` のようにグラフを**パラメータから作る**書き方（`tools/chem-source/chart-gen.cjs`。滴定曲線・溶解度曲線・エネルギー図・濃度の変化・気体の法則・状態図・冷却曲線・イオン化エネルギー）、`{"gen":"mol","name":"ethanol"}`（構造式の骨格式）、`{"gen":"pt","hl":["Ca","Sr","Ba"]}`（周期表の強調）が使える。図はすべて自前のSVG（外部の画像は使わない）。
- **計算テンプレート**: `T(id, 単元, レベル, 大学入試, 時間, gen(rng), {xo})`。`gen` が乱数から数字を決め、`{text, ans, unit, sig, tol, steps[]}`（問題文・正解・単位・有効数字・許容誤差・途中式）を返す。原子量は `AM` の表を使い、問題文に書く。`tests/chem.test.js` が、全テンプレートの自己検算と、代表的な問題の別式での検算をする。
- **作りかた**: `node tools/build-chem.mjs` が `data/chem.js` を作る（直接編集しない）。単元・レベル・選択肢の重なり・読みの文字・問題文の終わりなどを検査し、警告を出す。
- **品質**: 各バッチを書いたあとに、事実（物質量・pH・色・沈殿・酸化数など）を1問ずつ確認して直した。計算テンプレートは、誤りのあった十数個を書き直して検算テストを付けた。

## 友達対戦
`POST /room/new?game=chem` で部屋を作る。ホストが形式・学年・単元・難しさ・問題数を選び、2〜4人で開始。出題・採点・時間はサーバーが持ち、端末へは問題・制限時間・（締め切り後の）正解だけを送る。抜けた人の分は待たず、残りの人が全員答えたらすぐ答え合わせ（`docs/multiplayer.md`）。ゲーム中の途中参加はできない（再接続は可）。

## CPU（ひとり用）
| 形式 | やさしい | ふつう | むずかしい |
|---|---|---|---|
| 資料選択 の正解率 | 50% | 68% | 86% |
| 計算 の正解率 | 35% | 55% | 78% |
| 早押し「わかる」確率 | 30% | 50% | 76% |

レベルの高い問題ほど少し下がる。計算のまちがいは、桁やまるめのずれた値。
