# ミニネプリーグ（英語）

爆弾をまわしながら、お題に合う英単語を1つずつ答える。ひとり用（CPUと対戦）と、友達対戦（2〜4人）。

## ルール
- 1ラウンド = 爆弾1つ + お題1つ。**導火線は30秒で固定**（答えても延びない）。
- 爆弾を持っている人が1語答える。正解なら**となりの人（生きている人）へ爆弾が渡る**。まちがい・同じ答え・原形でない答えは受け付けず、爆弾は渡らないまま時間だけが進む。
- みんなで目標の数まで答えると**解除**。最後に答えた人に +20点（正解1つにつき +10点）。次のラウンドは、その次の人から。
- 導火線が切れると**爆発**。**爆弾を持っていた人だけ**ライフ(♥3)が1減る。0で脱落。爆発したときは「答えの例」を見せる。
- 最後の1人が勝ち。ラウンドが15に達したらライフ→得点の順で決める（完全に同じなら引き分け）。
- 導火線が切れた直後の1.5秒は、通信の遅れを考えて答えを受け付ける（`GRACE_MS`）。

### 目標の数（生きている人数 → 何個で解除）
30秒で答えられる量から決めた表（`js/games/nep/core.js` の `NEED`。遊んでみて調整する）。

| 難しさ | 2人 | 3人 | 4人 |
|---|---|---|---|
| やさしい | 3 | 4 | 5 |
| ふつう | 4 | 5 | 6 |
| むずかしい | 5 | 6 | 8 |

脱落者が出ると人数が減るので、目標も下がる。答えの数が限られるお題（熟語の穴うめなど）は、答えの数に合わせてさらに下げる。

## 答えのルール（原形）
- 英字だけの**1語**（`ice cream` のような複数語は不可）。2文字以上、単語リストにある語。
- **原形**で答える。`dogs` `played` `running` などの変化形は「原形で答えてね（dog）」と断る（`NepWords.baseOf`）。
  不規則変化（went→go、children→child など）は `tools/nep-source/irregular-forms.txt`。
  `news` `glasses` `morning` のように変化形に見えても1語として使う語は `keep-words.txt` で残す。
- 過去形のお題だけは過去形を答える。
- 同じ爆弾の中で同じ答えは使えない（別の爆弾では使える）。

## お題の種類（12）
| 種類 | 例 | 答えの判定 |
|---|---|---|
| letter | 「A」で始まる英単語 | 単語リストで頭文字が合う（x・z・q・y などは出さない） |
| length | 4文字の英単語 | 文字数が合う |
| endletter | 「E」で終わる英単語 | 最後の文字が合う |
| category | 🐶 動物（25カテゴリ） | 手で作った一覧 `categories.txt` |
| collocation | `ice ___`（cream / cube / age…） | 答えが何個もある穴うめ `collocations.txt` |
| phrase | `salt and ___` → pepper | 1つ答えるたびに別の慣用句 `phrases.txt` |

| translate | 「犬{いぬ}」→ dog | しりとり辞書の「子ども向けの語」(`data/words.js` の flag 4)。**同音異義語を見分けられるよう、漢字＋ふりがなで出す**（橋{はし}=bridge / 箸{はし}=chopsticks）。下の「日本語→英語の表記」参照 |
| antonym | hot → cold | `antonyms.txt` |
| past | go → went | `pasts.txt`（不規則動詞） |
| anagram | `G A T S N` → angst | 同じ文字でできた単語 |
| atoz | A→F の順（Aで始まる語、次はBで始まる語…） | 順番の頭文字が合う |
| chain | 英語しりとり（前の語の最後の文字から） | x z q j で終わったら次は何でもOK |

熟語の穴うめ(collocation)と慣用句(phrase)には、**日本語の意味**を「意味：塩とこしょう」の形で問題に添える（ヒント。ふりがな付き）。意味は `collocations.txt` `phrases.txt` の最後の欄で、ないと生成時に警告が出る。

やさしいでは past / anagram / chain / endletter を出さない。直前と同じ種類・使ったお題は避ける。

## 日本語→英語の表記
同音異義語（はし・くも・はな…）は、読みだけでは何のことか分からないので、問題は漢字で出してふりがなを付ける。表記は `tools/build-nep.mjs` が JMdict から引いて作る（`--jmdict` に `jamdict.db` を渡す）。
- 「食べ物」→ `食{た}べ物{もの}`（送りがなは外に出す。`Ruby.html` の書き方）。
- 辞書の「ふだんはかなで書く」語（苺・烏賊・兎など、難しい漢字）は、同じ読みの別の語がなければ**かな**のまま出す。同音異義語があるとき（雲/蜘蛛）は漢字で区別する。
- カタカナ語（コップ・ギター）はカタカナのまま。
- 辞書で見つからない語や、表記を手で決めたい語は `tools/nep-source/kanji-overrides.txt`（読み|表記）。
- 同じ表記の語は、答えをまとめる（1つの問題に答えが複数でもOK）。

## ヒント
自分の番に「💡ヒント（-5点）」を押すと、**正解の1つの頭文字と文字数**（例: `P _ _ _ _ _（6文字）`）が**全員の画面**に出る。
- 1人につき1ラウンドに1回。持っている人だけ押せる。点数が足りなければ0まで引く（`HINT_COST` = 5）。
- 答えて爆弾が次の人に渡ると、ヒントは消える（次の人は自分のヒントを使える）。
- ヒントの語は、知られている語（知名度の高い順の上位）から選ぶ。カテゴリ・慣用句など手作りの一覧は全部から選ぶ。
- 友達対戦では `{t:"hint"}` を部屋に送る。ヒントの内容は頭文字と文字数だけで、答えそのものは送らない。

## CPU（ひとり用）
知っている語の広さ・考える時間・まちがい率を難しさで変える（`js/games/nep/cpu.js`）。

| 難しさ | 知っている語 | 考える時間 | まちがえる確率 |
|---|---|---|---|
| やさしい | 上位6,000語 | 2.5〜6秒 | 15% |
| ふつう | 上位15,000語 | 2〜4.5秒 | 8% |
| むずかしい | 30,000語すべて | 1.2〜3.2秒 | 3% |

カテゴリや熟語など手作りの一覧は、広さの制限なく選ぶ。

## 構成
| ファイル | 役割 |
|---|---|
| `tools/nep-source/*.txt` | 手で作るお題（カテゴリ・穴うめ・慣用句・反対語・過去形・変化形の表・残す語）。編集して下の手順で再生成 |
| `tools/build-nep.mjs` | `data/nep.js` を作る（頻度表の上位30,000語から、変化形・短縮形のかけら・略語・不適切語を除く。JMdictから日→英の漢字表記も引く） |
| `data/nep.js` | 生成物（約300KB）。ひとり用を始める時に読み込む。Worker も同じファイルを使う |
| `js/games/nep/words.js` | 単語リスト・原形判定（`baseOf`）・頭文字/長さ/アナグラムの索引 |
| `js/games/nep/topics.js` | お題づくり・今の問題(prompt)・答え合わせ(judge)・候補一覧 |
| `js/games/nep/core.js` | 進行（爆弾・ライフ・解除/爆発・ラウンド）。時間は呼び出し側が渡す |
| `js/games/nep/cpu.js` | CPUの考え方 |
| `js/games/nep/board.js` | 対戦画面（ひとり用・友達対戦で共通）と結果画面 |
| `js/games/nep/game.js` `store.js` | メニュー・ひとり用・戦績の保存 |
| `js/games/nep/online.js` | 友達対戦の画面（部屋・QR・ロビーは `shiritori/online.js` と共通） |
| `worker/nep-room.mjs` | 部屋の進行（サーバー）。お題・導火線・採点はサーバーが持つ |

友達対戦では、**お題の答えの一覧(topic)は端末に送らない**。端末へは今の問題(prompt)・出た答え・導火線の終了時刻だけを送る（`publicState`）。導火線の時間はサーバーの時計で数え、Durable Object のアラームで爆発・次のラウンドを進める。

## データの作り直し
```sh
node tools/build-nep.mjs --freq <subtlex の index.json> --profanity <google-profanity-words の data/en.txt> \
     --jmdict <jamdict.db> --stats
```
警告（使えない形の語・答えが少ないお題）が出たら `tools/nep-source/` を直す。出典は `data/README.md`。

## 省電力
ずっと動くアニメーションは使わない。導火線のバーと数字は1秒に1回だけ更新（`Fx.timerBar`）、動きは正解・爆発・解除の1回きりの演出だけ（`docs/battery.md`）。ひとり用の進行は250msごとのタイマー1つ。タブが裏に回った間は時間を止める。
