# 英単語しりとり 設計メモ

## 決定事項
- 対象: 小学生〜高校生（大人も可）。難易度はやさしい/ふつう/むずかしいで単語を出し分ける。
- 入力フロー: **B案**（かな読み → 英語スペルの2段階）。やさしいモード(A案: 英語のみ)は後日。
- 判定は三段構え: ①ルール判定 → ②ローカル辞書 → ③Gemini(辞書にない時のみ・結果は保存)。
- Gemini中継: Cloudflare Workers 無料枠（段階5で作る。APIキーはブラウザに置かない）。

## ルール
| 項目 | 内容 |
|---|---|
| 「ん」で終わる | 負け |
| 同じ単語 | 禁止（英語スペルが同じなら重複。読みが同じでも別の単語ならOK） |
| 小さい「ゃゅょっ」 | 大きい字に直してつなぐ（しゃ→や） |
| 「ー」 | 無視して、その前の母音でつなぐ（コーヒー→い） |
| 濁点 | 設定で切替（ご→こ でもOKにするか。標準は厳密＝OFF） |
| 英語 | 英字のみ2〜30字の1単語、大文字小文字は無視、米英どちらの綴りもOK |
| 品詞 | 最初は名詞のみ（固有名詞は除外） |
| 制限時間 | 1ターン約30秒 |
| ヒント | 頭文字を教える代わりに得点を引く |
| 復習 | 間違えた単語を保存してあとで復習 |

## 判定フロー
```
入力(かな, 英語)
 ├─ ① ルール判定  rules.js   形式 / つながり / 重複 / ん
 ├─ ② 辞書照合   (読み, 英語)のペア
 ├─ ③ キャッシュ  過去のGemini判定
 └─ ④ Gemini     Workers経由（失敗時は「辞書にない単語」）
```

## 進行
1. ルール判定とテスト ← 実装済み
2. 英語・かなキーボード ← 実装済み
3. 辞書づくり（JMdict, CC BY-SA 4.0: クレジット表記が必要） ← 実装済み（data/words.js、tools/build-dict.mjs）
4. 対CPU戦（ここでGeminiなしで遊べる） ← 実装済み
5. Gemini中継（Cloudflare Workers） ← コード実装済み。デプロイは docs/gemini-worker-setup.md の手順で
6. 復習リスト・効果音・仕上げ

## 対CPU戦の仕様（段階4で実装）
- 開始: 「しりとり」→ プレイヤーは「り」から。CPUは手選びの語 → 日常語の順に選び、「ん」で終わる語は出さない。
- むずかしさ: やさしい(45秒・♥5・CPUはレベル1) / ふつう(30秒・♥3・レベル2) / むずかしい(20秒・♥3・レベル3)。
- ライフが減る: つなぎ違い・重複・つづりミス・読みと英語が合わない・時間切れ。
  減らない: 入力形式のミス、辞書にない語（段階5でGeminiが判定する）。
- 終了: ライフ0 / 「ん」で終わる / CPUが出せなくなった(勝ち)。
- 得点: (10 + 文字数×2 + はやさ0〜10 + れんぞく最大10) × 倍率(1 / 1.5 / 2)。ヒントは-5点（0未満にならない）。
- ヒント: つながる語の読みと、英語の頭文字・文字数を教える。
- ふくしゅう: つづりミス・不一致の「正解」をlocalStorageに保存（最大200件、同じ語はまとめる）。
- 実装: `game-core.js`（進行・得点。画面に依存せずテスト済み）/ `store.js`（保存）/ `game.js`（画面）。
