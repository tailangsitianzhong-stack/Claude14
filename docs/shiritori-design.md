# 英単語しりとり 設計メモ

## 決定事項
- 対象: 小学生〜高校生（大人も可）。難易度はやさしい/ふつう/むずかしいで単語を出し分ける。
- 入力フロー: **B案**（かな読み → 英語スペルの2段階）。やさしいモード(A案: 英語のみ)は後日。
- 判定は三段構え: ①ルール判定 → ②ローカル辞書 → ③Gemini(辞書にない時のみ・結果は保存)。
- Gemini中継: Cloudflare Workers 無料枠（段階5で作る。APIキーはブラウザに置かない）。

## ルール
| 項目 | 内容 |
|---|---|
| 「ん」で終わる | 負け |
| 同じ単語 | 禁止（英語スペルが同じなら重複。読みが同じでも別の単語ならOK） |
| 小さい「ゃゅょっ」 | 大きい字に直してつなぐ（しゃ→や） |
| 「ー」 | 無視して、その前の母音でつなぐ（コーヒー→い） |
| 濁点 | 設定で切替（ご→こ でもOKにするか。標準は厳密＝OFF） |
| 英語 | 英字のみ2〜30字の1単語、大文字小文字は無視、米英どちらの綴りもOK |
| 品詞 | 最初は名詞のみ（固有名詞は除外） |
| 制限時間 | 1ターン約30秒 |
| ヒント | 頭文字を教える代わりに得点を引く |
| 復習 | 間違えた単語を保存してあとで復習 |

## 判定フロー
```
入力(かな, 英語)
 ├─ ① ルール判定  rules.js   形式 / つながり / 重複 / ん
 ├─ ② 辞書照合   (読み, 英語)のペア
 ├─ ③ キャッシュ  過去のGemini判定
 └─ ④ Gemini     Workers経由（失敗時は「辞書にない単語」）
```

## 進行
1. ルール判定とテスト ← 実装済み
2. 英語・かなキーボード ← 実装済み
3. 辞書づくり（JMdict, CC BY-SA 4.0: クレジット表記が必要）
4. 対CPU戦（ここでGeminiなしで遊べる）
5. Gemini中継（Cloudflare Workers）
6. 復習リスト・効果音・仕上げ
