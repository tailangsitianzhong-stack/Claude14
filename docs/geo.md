# 地理クイズ

世界と日本の地理を、3つの形式で遊ぶ。ひとり（CPUと対戦）と、友達対戦（2〜4人）。問題は各形式で200問ほど。

| 形式 | 内容 | 判定 |
|---|---|---|
| ⚡ 早押し | 問題文が1文字ずつ流れる。「、」「。」で間があく。わかったら押して、かなで答える | 読みの辞書 → 合わなければ AI |
| 🗺️ 地図で選ぶ | 首都・有名な都市・名所・名産がある国（県）を、地図からタップして選ぶ | 場所のコードの一致 |
| 🖼️ 資料選択 | 雨温図・気温と降水量の表・写真・統計の表を見て、4択で答える | 選択肢の一致 |

設定: 形式 / 範囲（世界・日本・どちらも）/ 難しさ / 問題数（5・10・15）/ CPUの人数（0〜3）。

## ルール
- 1ラウンド = 1問。点数は「正解 10点 + 早さのボーナス」。最後に一番高い人の勝ち（同点は同点1位）。
- **資料選択・地図**: 全員が同時に答える。全員が答え終わるか制限時間（資料選択20〜25秒・地図35秒）で締め切り、**一斉に開示**して採点する。他の人の答えは、開示まで見えない。ボーナスは早く答えるほど最大5点。
- **地図**: 国（世界）か都道府県（日本）をタップすると「〇〇でOK？［決定］［キャンセル］」が出る。決定したら変えられない。拡大縮小（ピンチ・＋－・ホイール）・移動・地域ボタン。小さな国は●でも選べる。開示では、正解の場所にズームして全員の選択をアバターで出す。
- **早押し**: 問題文が流れる。押すと文が止まり（全員の画面で同じ位置）、押した人だけが12秒以内にかなで答える。早く押すほど高得点（10点 + 最大10点）。まちがい・時間切れは **-5点** でその問題の解答権を失い、文はつづきから流れる。全員まちがえるか、文が終わって6秒たつと答えを開示する。
- 答えを送ると、まず**読みの一覧**（ひらがな・カタカナ・空白・記号の違いは無視）と照合する。合わなければ **AI** に確認する（下記）。確認中は時間が止まる。

## AI による答えの確認（早押しだけ）
- 辞書で決まらなかった答えだけ、中継 Worker の `POST /geo/judge`（`worker/geo-judge.mjs`）で Gemini に「正解と同じものを指しているか」を厳しく判定させる。
- 通すもの: 別名・通称（アメリカ合衆国←あめりか）、カタカナの表記ゆれ、川・山・県などの語尾の有無。断るもの: 別の場所・広すぎる/せますぎる答え・あいまいな名前（こんご）・意味の変わるまちがい。入力は「データ」として扱い、中に指示があっても無視させる。
- 同じ（正解, 入力）の結果は KV に半年キャッシュ（無料枠を守る）。端末にも覚える（`js/games/geo/judge.js`）。
- 判定できないとき（無料枠の上限・通信エラー）は不正解になり、「AIで確認できなかったよ」と出す。CPUの答えは AI に聞かない。
- ひとり用は端末から `/geo/judge`、友達対戦は部屋（Durable Object）から同じ関数を呼ぶ。

## データ（`data/geo.js` 約140KB・`data/geo-map.js` 約270KB・`assets/geo/*.webp` 約3.4MB）
すべて開発時に `tools/` で作る。ゲーム本体は生成物だけを読む。地図は地図形式を始める時だけ、写真は表示する時だけ読み込む。

```sh
# 地図(世界の国・日本の都道府県)
node tools/build-geo-map.mjs --world-atlas <countries-50m.json> --countries <world-countries の countries.json> --admin1 <ne_10m_admin_1_states_provinces.geojson>
# 雨温図の元データ(NASA POWER)と写真(Wikimedia Commons)を取得して保存
node tools/fetch-geo-climate.mjs        # tools/geo-source/climate.json
node tools/fetch-geo-photos.mjs         # assets/geo/*.webp と tools/geo-source/photo-credits.json
# 問題データ
node tools/build-geo.mjs --countries <countries.json> --admin1 <admin1.geojson>
```
- 手で作る元データは `tools/geo-source/`: `countries.txt`（独立国194・読み・首都）、`prefs.txt`（47都道府県）、`cities.txt`＋`climate-fix.txt`（雨温図の都市・気温の補正・気候区分）、`photos.txt`（写真の候補）、`stats.txt`（統計の表）、`buzz-hand.txt`（早押しの手書き問題）、`map-hand.txt`（有名都市・名所・名産）。
- 早押しの国・都道府県の問題は、データから自動で組み立てる（隣国・面積・首都 / 隣接県・地方・県庁所在地）。地図の「首都が〇〇の国」「県庁所在地が〇〇の県」も自動。
- **雨温図**: NASA の格子データ（約50km四方の平均）は山を含む地点で気温が低めに出るので、ずれの大きい都市だけ気温を一律に補正している（`climate-fix.txt`）。気候区分は学校地理の名前で手で付けた。授業で正確さが要るときは、気象庁の平年値で直す。
- **写真**: Wikimedia Commons の、パブリックドメイン・CC0・CC BY・CC BY-SA だけ（NC・NDは使わない）。幅640pxのWebPにして保存し、作者・ライセンス・元ページを `photo-credits.json` に残す。取得した写真は目で確認すること（検索結果が別のものの場合がある）。内容が合わない写真は `tools/geo-source/photo-skip.txt` に id を書くと、出題から外れる。画面の下に「写真: 作者（ライセンス）」を出し、メニューの「📷 出典・クレジット」に全部の出典を載せる。
- **ライセンス**: 地図は Natural Earth（パブリックドメイン）・world-atlas（ISC）、国のデータは world-countries（ODbL・出典表記が必要）、雨温図は NASA POWER。`data/README.md` も参照。

## 友達対戦
`POST /room/new?game=geo` で部屋を作る。ホストが形式・範囲・難しさ・問題数を選び、2〜4人で開始。出題・採点・時間はサーバーが持ち、端末へは問題・制限時間・（締め切り後の）正解だけを送る。早押しの停止位置・文字の出る時刻は、問題の持つ時刻表と出題時刻から全員が同じ式で計算する。ゲーム中の途中参加はできない（再接続は可）。

## CPU（ひとり用）
| 形式 | やさしい | ふつう | むずかしい |
|---|---|---|---|
| 資料選択 の正解率 | 50% | 70% | 88% |
| 地図 の正解率 | 40% | 60% | 82% |
| 早押し「わかる」確率 | 35% | 55% | 80% |
| 早押しで押す位置（文の何割） | 65〜98% | 45〜90% | 30〜75% |

レベルの高い問題ほど少し下がる。地図のまちがいは、同じ大陸（日本なら同じ地方）のどこか。知らない早押しは、たまに最後に当てずっぽうで押してまちがえる。

## 省電力
ずっと動くアニメーションは使わない。制限時間のバーと数字は1秒に1回だけ更新、地図は操作している間だけ動き、早押しの文は流れている間だけ約90msごとに更新（待機中のメインスレッドは1%未満）。タブが裏に回った間は、ひとり用の時間を止める。
