# 友達対戦（最大4人）

対応ゲーム: **しりとり**（この文書）と **ミニ漢字検定**（`docs/kanken.md`）。部屋・番号・QR・ロビーは共通で、部屋を作る時に `POST /room/new?game=kanken` のように種類を伝えます。

無料の Cloudflare Workers + Durable Objects（WebSocket）で動く、部屋方式の対戦です。追加の登録や費用は要りません。

## 遊び方
1. メニュー →「👥 友達と遊ぶ」→「部屋を作る」。**5桁の部屋番号**と**QRコード**が出ます。
2. 友達は、QRコードを**スマホのカメラで読み取る**（そのまま部屋に入れる）、または「部屋に入る」で番号を入力。「🔗 リンクをコピー」「📤 送る」でも招待できます。
3. 2人以上そろったら、ホストが難しさを選んで「スタート」。順番に答えます。
4. ライフ（♥）が0になるか、「ん」で終わると脱落。**最後まで残った人の勝ち**。終わったらホストが「もう一度」でロビーに戻れます。

## しくみ
```
端末A ─┐
端末B ─┼─ WebSocket ─ 部屋（Durable Object / 部屋番号ごとに1つ）
端末C ─┘              順番・制限時間・ライフ・得点・使用済み単語を管理
```
| 役割 | 担当 |
|---|---|
| つづり・意味の判定（辞書 / Gemini） | **答える人の端末**。通った手だけを部屋へ送る（友達同士なので信頼する） |
| つながり・重複・「ん」・順番・制限時間 | **部屋（サーバー）**。端末の時計をいじってもズルできない |

- 手番ごとに制限時間（やさしい45秒/ふつう30秒/むずかしい20秒）。時間切れ・間違いはライフ-1で、次の人へ。
- 切断しても席は残り、同じスマホで自動再接続（部屋のURLを開き直しても戻れる）。
- ロビーで抜けた人は席が空き、ゲーム開始後は途中参加できない。
- 誰もいなくなった部屋は、約10分で自動的に片づけられる。

## ファイル
| ファイル | 内容 |
|---|---|
| `worker/room-logic.mjs` | 進行ロジック（純粋な関数。`tests/room-logic.test.js`） |
| `worker/room-do.mjs` | Durable Object（WebSocket中継・保存・制限時間のアラーム） |
| `worker/main.mjs` / `index.mjs` | 入口（`POST /room/new`、`GET /room/12345` のWebSocket） |
| `js/games/shiritori/net.js` | ブラウザ側の通信（自動再接続・サーバー時計との差の補正） |
| `js/games/shiritori/online.js` | 画面（入口・番号入力・ロビー・対戦・結果） |
| `js/vendor/qrcode.js` | QRコード生成（qrcode-generator, MIT） |

## 無料枠の目安（Cloudflare Workers Free）
Durable Objects は1日 100,000 リクエスト、13,000 GB-s まで（上限を超えても請求はされず、その操作が失敗するだけ。毎日0:00 UTCにリセット）。
WebSocketは休止(Hibernation)に対応していて、操作が無い間は時間課金が増えません。友達同士で遊ぶ規模ではまず使い切りません。

## 注意
- 部屋番号は5桁なので、他人が偶然同じ番号を入力すると入れてしまいます（開始前のロビーでのみ）。知らない人が入ったら、部屋を作り直してください。
- 判定は答える人の端末で行うため、改造した端末なら不正な手を送れます（友達同士の遊びを想定）。
