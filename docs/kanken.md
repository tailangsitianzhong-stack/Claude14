# ミニ漢字検定

常用漢字 2,136字（小1〜高3で習う範囲）と、漢検1級用の表外漢字（約4,200字）から、**読み（ひらがな入力）**と**漢字（4択）**をランダムに出題するゲームです。

## モード（メニューで選ぶ）
| モード | 内容 |
|---|---|
| ⏱️ タイムアタック | **60秒**で何問解けるか。ライフなし。間違えても続く（0点・連続が途切れる）。「パス」もできる |
| 🔥 サバイバル | 1問ごとに制限時間。**時間切れ1回か、ライフ(♥3)が0**で終了。最大何問解けるか |
| 📝 ミニ検定 | **最大60問**。1問ごとに制限時間とライフ(♥5)。時間切れもライフ-1。何問正解で何ポイントか。70%（42問）以上で合格 |

## レベルとポイント
| Lv | 範囲 | 字数/語数 | 基本点 |
|---|---|---|---|
| 1 | 小学1〜2年 | 240字 | 10 |
| 2 | 小学3〜4年 | 420字 | 20 |
| 3 | 小学5〜6年 | 366字 | 30 |
| 4 | 中学〜高校（よく使う半分） | 555字 | 50 |
| 5 | 中学〜高校（残り）。応用 | 555字 | 80 |
| **6 漢検2級** | 常用漢字だけの語のうち、難しい漢字を2字以上含む語・やや珍しい語 | 約250語 | 120 |
| **7 漢検1級** | **常用漢字以外の漢字**（JIS第一・第二水準の表外漢字 約4,200字）を含む語 | 約360語 | 200 |

- 選んだレベルが中心で、約3割は易しいレベルの語から出ます（Lv1〜5はLv1から、漢検2級・1級は1〜2つ下のレベルから混ぜます）。
- **得点 = 基本点 × 形式の倍率（読み×1.5／4択×1） ×（1 + はやさ最大+50% + 連続正解 1問+10%・最大+50%）**
- 1問の制限時間: 読み30秒／4択12秒。
- 漢検1級・2級は、語の数が少ないので、同じ問題が繰り返し出ることがあります。
- 漢検2級・1級の語は、固有名詞（地名・人名）と、子ども向けにふさわしくない字を含む語を除いています。

## 問題の作り
- **読み**: 熟語を出し、その読みをひらがなで答えます。読みが1通りに決まる語だけ使い、「ぢ/づ」「じ/ず」の違いとカタカナは正解にします。
  - **送りがな付きの語（教える・高まり）は、漢字の部分だけを答えます**。線を引いた漢字（**教**える）の読み「おし」が正解で、送りがなまで入力（おしえる）しても正解です。
  - 語の形は「漢字だけ」か「漢字＋送りがな」のみです（読みが12文字を超える語は除外）。
- **漢字（4択）**: 読みつきで、漢字の一部を「□」にした熟語を出します。4択の「にせ漢字」は**同じ音読みの別の常用漢字**（同じ部首・近い画数・近いレベルを優先）で、置きかえた語が辞書に実在する字は使いません。

## 友達対戦（最大4人）
メニューの「👥 友達と遊ぶ」から。部屋・5桁の番号・QRコードの仕組みはしりとりと同じです（`docs/multiplayer.md`）。QRコードのリンクは `?room=12345&game=kanken` で、読み取るとミニ漢字検定の部屋にそのまま入ります。

- **同じ問題を全員の画面に出し、答えられるのは順番の人だけ**。1問ごとに次の人へ交代します（脱落した人は飛ばす）。
- モードは **ミニ検定（最大60問・ライフ♥5・時間切れもライフ-1）** と **サバイバル（ライフ♥3・時間切れは即脱落・問題数は無制限）** の2つ。ホストがロビーでモードとレベルを選びます。
- **最終的な勝者はポイントで決まります**（同点は正解数 → 生き残り）。
- 終了: ミニ検定は60問目まで / 全員脱落 / 1人だけ残っていて、その人が最高得点（これ以上競う相手がいない）。
- **出題・採点・制限時間は部屋（サーバー）が行い、答えは誰の端末にも送りません**（`worker/kanken-room.mjs`）。画面を覗いても、通信を見ても、答えは分かりません。
- **答えは、正解でも不正解でも、全員の画面に出ます**（例:「🐱 ⭕ 正解！ +47点　答え：福岡→ふくおか」「🐶 ❌　答え：水（水分）」）。ゲームが終わったあとも、結果画面に最後の問題の答えが残ります。
- 間違えた語は、答えた本人の復習リストに保存されます。

## ファイル
| ファイル | 内容 |
|---|---|
| `tools/build-kanji.mjs` | 出題データ(`data/kanji.js`)の生成ツール（JMdict + KANJIDIC2）。`--stats` で統計表示 |
| `data/kanji.js` | 生成物。常用漢字2,136字・語約14,500語（うち書き取り(4択)にできるのは約9,000語） |
| `js/games/kanken/question.js` | 問題づくり・答え合わせ・得点（純粋な関数） |
| `js/games/kanken/core.js` | 3モードの進行（時間は呼び出し側が渡す） |
| `js/games/kanken/store.js` | ベスト記録・復習リスト（この端末に保存） |
| `js/games/kanken/game.js` | 画面（メニュー・プレイ・結果・復習） |
| `js/games/kanken/online.js` | 友達対戦の画面（ロビーの設定・対戦・結果。部屋の共通部分は `shiritori/online.js`） |
| `worker/kanken-room.mjs` | 友達対戦の進行ロジック（出題・採点・順番・終了。`tests/kanken-room.test.js`） |
| `tests/kanken.test.js` | データの整合性・出題・得点・3モードの進行のテスト |

## データの再生成
```sh
node tools/build-kanji.mjs <jamdict.db> --out data/kanji.js --stats
```
（`jamdict.db` の入手は `data/README.md` を参照）熟語が1つも見つからない約110字（地名用の字など）は、出題されません。
