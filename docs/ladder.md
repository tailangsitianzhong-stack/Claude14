# 英単語トランスミッション

スタートの単語から、**同じ位置の文字を1つずつ変えて**、ゴールの単語まで、途中もすべて意味のある英単語でつなぐゲーム（ワードラダー）。例: ROCK → LOCK → LOOK（岩 → 鍵 → 見る）。ひとり（練習）と、友達対戦（2〜4人の**協力**）。文字を「ダイヤル」のように回して選ぶ。

## 遊びかた
- 画面に、ゴールの単語（意味つき）と、つながった単語の列（変わった文字が光る・意味つき）、次の単語をつくる**ダイヤル**が出る。
- ダイヤルの ▲▼ で文字を回す（長押しで連続）。文字そのものをタップすると A〜Z から選べる。**変えられるのは1か所だけ**（ほかの文字は、もとにもどる）。キーボードでも打てる（←→ で位置、A〜Z、Enter）。
- 「ギアを入れる」で出す。**ふつうの英単語（約7千語）は、AI を待たずに、その場で認められる**。意味（日本語）は、辞書か手書きの意味があればすぐ出て、なければ「意味を調べ中…」のあとに、AI がつけた意味が「AI」の印つきで出る（待たずに次の人へ進める）。
- 一覧にない単語（**NIKE・PARIS のような、広く知られた固有名詞**など）は **AI が確認**する（確認中は「🔍 AI が確認中…」。時間は止まる）。認められれば、意味（例: ナイキ（スポーツ用品のブランド））が出る。
- ゴールの単語を出したらクリア。

**ギア（ライフ）**: チームで3つ。次のとき1つ減って、0でおしまい。
- 単語として認められなかった（AI が不可）
- 手番の時間切れ（友達対戦）
- 「1手戻す」を使った
- 使った単語・2文字以上ちがう語・文字数が合わない語は、**ギアを減らさずに断る**（やり直せる）。AI が使えなかったときも、ギアは減らない。
- 手数が40を超えても、止まる（失敗）。

**ヒント**（チームで3回）: 1回目 ゴールまで文字があといくつちがうか・辞書の単語だけなら最短あと何手 → 2回目 次に変える位置 → 3回目 その位置の文字。

**星**: 辞書上の最短の手数（par）以内でクリアなら ★3、+2手以内で ★2、それ以上は ★1。終了後に、もっと短い道があれば見せる。

**難しさ**: やさしい（3文字・最短2〜3手）/ ふつう（4文字・3〜5手）/ むずかしい（5文字・4〜9手）。ひとりのときは、制限時間を「あり」にもできる（1手ごとに 60 / 50 / 45秒。友達対戦は、つねにあり）。

**友達対戦**: ホストが難しさを選び、2〜4人で開始。**順番に1語ずつ**出す。盤面・ギア・ヒントは全員で共通。抜けた人の手番は飛ばす（待たない）。AI の確認も、手番・時間も、部屋（サーバー）が持つ。

## 単語データ（`data/ladder.js`）
`node tools/build-ladder.mjs <jamdict.db>` が作る（直接編集しない）。
- **意味つきの辞書**: 約1,900語（3文字 257・4文字 868・5文字 811）。JMdict（日本語→英語）を逆に引いて、英単語ごとの日本語の意味（「岩（いわ）」のように漢字と読み）と品詞をつけた。日常語の印がある語義だけを採り、不適切な語は入れていない。意味は逆引きなので「代表的な意味の目安」。パズルは、この辞書の単語だけで作る。
- **手書きの意味**: 機能語（for・with・can…）と不規則動詞の活用形（done・gone・went・saw…）約160語（`tools/ladder-source/extra-words.txt`）。逆引きでは意味がずれる語に、正しい意味をつけた。
- **ふつうの英単語の一覧**: 約7千語（`tools/ladder-source/english-words.txt`。an-array-of-english-words 2.0.0（MIT）から、不適切語（@coffeeandfun/google-profanity-words）などを除き、さらに「JMdict の訳語に小文字で出てくる語」か「SUBTLEX の語彙表にある語」（とその規則変化）だけに絞った 3〜5文字の語。めずらしい Scrabble 用の語は入れない）。ここにある語は、**AI を待たずに、その場で認める**。意味は、辞書か手書きの意味になければ、あとから AI に聞く。
- **規則変化**: 意味つきの語（辞書・手書き）の複数形・三単現（-s -es）・過去形（-ed -d）は、同じ文字数なら、もとの語の意味を使って認める。
- **パズル**: 辞書の単語だけでつなぐと必ず解ける組を、幅優先探索（BFS）で作った。450問（やさしい110・ふつう150・むずかしい190）。最短の手数（par）も記録（`tests/ladder.test.js` が全体の整合を確認）。
- ふつうの英単語の一覧の語（めずらしい語を含む）も使えるので、辞書上の最短より短くつながることがある。ヒントは、よく使う単語の道を優先し、めずらしい語まで使うと短い場合は、その手数も教える。

## AI による確認
- 一覧にない単語だけ、中継 Worker の `POST /ladder/judge`（`worker/ladder-judge.mjs`）で Gemini に聞く。意味がなくて「あとから意味をつける」ときも、同じ窓口を使う。
- 認める: 一般的な英語辞書にのっている語とその規則変化（複数形・三単現・過去形・-ing）、**広く知られた固有名詞**（国・主要な都市・有名な人物や神話の名前・有名なブランドなど。大文字小文字は気にしない）。認めない: 無名の名前・架空の名前・略語・辞書にないスラング・外国語・つづりまちがい・不適切な語。入力は「データ」として扱い、中の指示は無視させる。
- 認めたときは、品詞と**短い日本語の意味**（24字まで。固有名詞はカタカナの名前と何かを書く）も返し、画面に出す。
- 結果は KV に1年キャッシュ（キーは `ladder2:単語`。判定の基準を変えたときは番号を上げる。無料枠を守る）。端末にも覚える（`js/games/ladder/judge.js`）。確認できなかったとき（無料枠の上限・通信エラー）は、キャッシュせず、ギアも減らさず、やり直せる（意味をあとからつける場合は、「意味は見つからなかったよ」と出して先へ進む）。
- 地理・化学・しりとりの判定と同じ `GEMINI_API_KEY` / `GEMINI_MODEL` / `CACHE` を使う。

## 構成
| ファイル | 役割 |
|---|---|
| `js/games/ladder/dict.js` | 辞書（意味・規則変化・1文字ちがいの単語・最短のつなぎかた）。画面・サーバー・テストで共通 |
| `js/games/ladder/core.js` | 進行（検証・手番・ギア・ヒント・1手戻す・離脱・星）。ひとり用と部屋で共通 |
| `js/games/ladder/board.js` | 対戦画面（ゴール・単語の列・ダイヤル・ヒント）。ひとり用と友達対戦で共通 |
| `js/games/ladder/game.js` `store.js` | メニュー・ひとり用・記録 |
| `js/games/ladder/judge.js` | AI 確認の窓口（結果の記憶つき） |
| `js/games/ladder/online.js` | 友達対戦の画面（部屋・QR・ロビーは `shiritori/online.js` と共通） |
| `worker/ladder-room.mjs` | 部屋の進行（サーバー）。手番制で通信が少ない |
| `worker/ladder-judge.mjs` | AI 判定（Gemini）と KV キャッシュ |
| `css/ladder.css` | スタイル |

省電力: 3Dや無限アニメーションは使わない。動きは、単語が入る一瞬とギアがゆれる一瞬だけ（`docs/battery.md`）。
