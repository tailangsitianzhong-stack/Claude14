# 効果音・演出・仕上げ（段階6）

## 効果音（`js/sfx.js`）
音のファイルは使わず、ブラウザの Web Audio で**その場で合成**します（無料・追加の読み込みなし）。

| 名前 | 使う場面 |
|---|---|
| `tap` / `key` | ボタン / キーボードを押した時（`Sfx.attach` が画面全体に付ける。4択ボタンは鳴らさない） |
| `ok` / `ng` | 正解 / 間違い・時間切れ |
| `pop` | CPUや相手の手、部屋に人が入った・出た時 |
| `heart` | ライフが減った・脱落 |
| `tick` | 残り3秒（自分の番だけ） |
| `turn` | 友達対戦で自分の番になった時 |
| `start` / `win` / `lose` / `end` | 開始 / 勝ち・合格・新記録 / 負け / 終了 |

- **設定**（ホーム →「設定」）: 音のON/OFF・音量・バイブ（バイブは対応する端末だけ）・テスト音。この端末に保存されます。
- スマホ(iOS)は画面を触るまで音を出せないので、最初のタップで準備します。音が出せない環境でも、ゲームは止まりません。
- バイブは、間違い・脱落・負け・勝ちの時だけ（音をオフにしても、バイブの設定は別に効きます）。

## 演出（`js/fx.js` / `css/fx.css`）
- 間違い: 揺れる（`shake`）、ライフがぶるっと震える。 正解: メッセージが弾み、得点が浮かんで消える（`+24`）。
- 勝ち・合格・新記録: **紙吹雪**。結果画面がぽんっと現れ、アイコンが弾む。
- 残り5秒以下: タイマーが点滅。 自分の番: 帯が緑になり、少し弾む。
- ホーム: タイトルがゆらゆら、ゲームカードが順に現れる、背景にクレヨン風の星・ハートがゆっくり動く。
- **「動きを減らす」設定（OSの設定）をオンにしている人**には、アニメーションと紙吹雪を出しません。

## ホーム画面に追加（`manifest.webmanifest` / `assets/`）
iPhone は Safari の「共有 → ホーム画面に追加」、Android は Chrome のメニューから追加すると、アプリのようにアドレスバーなしで開けます（アイコンは `assets/icon.svg` から `node tools/make-icons.mjs` で作成）。

## 公開
ルートの `wrangler.jsonc` に `build.command` を書いてあり、公開のたびに `index.html` `manifest.webmanifest` `css` `js` `data` `assets` を `public/` に集めます（ダッシュボードのビルドコマンドを直さなくても、新しいファイルが漏れません）。
