# 二択クイズ

トロッコに乗って分かれ道へ。左右の二択のうち、正解の側のパネルは突き破れるが、まちがいの側は固い壁にぶつかる。**英語・化学・物理・地理**を、すべて**大学入試（共通テスト・二次）レベル**の二択で出す。ひとり（個人戦）と、友達対戦（2〜4人・同じ画面を全員のトロッコが走る）。

## 遊びかた
1. 問題と、左右の選択肢が出る。制限時間は問題の長さで変わる（やさしい 16 秒・ふつう 12 秒・むずかしい 9 秒＋長い問題は加算。図のある問題は +6 秒）。
2. 画面の A / B をタップ（キーボードは ←→・A D・1 2）。決めたら変えられない。
3. 全員が答える（または時間切れ）と、答え合わせ。正解の人のトロッコはパネルを突き破り、まちがい・時間切れの人は壁（時間切れは中央の柱）にぶつかって弾き飛ばされる。解説が1行出る。

**モード**: 10問・20問・30問 / **サバイバル**。サバイバルは、ミス（時間切れも）3回でおしまい（友達対戦は全員のライフがなくなるまで）。進むほど、制限時間が短く（最短で6割）、発展の問題が出やすくなる。
**科目**: 英語・化学・物理・地理（いくつでも選べる。科目が先に選ばれるので、問題の多い科目だけに偏らない。同じ科目が3回続かない）。
**難しさ**: やさしい（基礎中心）・ふつう・むずかしい（発展中心）。問題の `ex`（1=基礎 / 2=標準 / 3=発展）の出やすさを変える。
**3D表示**: ON（トロッコが走る）/ OFF（かんたん・省電力）。WebGL が使えない端末は、自動で OFF と同じ表示になる。

**得点**: 正解 10点 + 早さのボーナス（最大 10点）+ 連続正解のボーナス（2回目から +2点ずつ、最大 +10点）。まちがい・時間切れは 0点で、連続がとぎれる。
**記録**（端末に保存）: モードごとの、ベスト得点・最高の連続正解・（サバイバルの）最長問題数。

## 問題（`data/duo.js` + 化学・地理の変換）
| 科目 | もと | 数 |
|---|---|---|
| 英語 | 手書き（語法・文法・時制・仮定法・関係詞・前置詞・熟語・語彙・つなぎ言葉・アクセント・会話表現・和文英訳の二択）`tools/duo-source/en-*.txt` | 約280 |
| 物理 | 手書き（力学・熱・波動・電磁気・原子・単位と総合）`tools/duo-source/phys-*.txt` | 約330 |
| 地理 | 世界銀行の統計から**自動で作る比較**（「人口が多いのは？」「平均寿命が長いのは？」など 7 指標）196 + `data/geo.js` の基本問題（大学入試の印があるもの）を二択に変換 | 約440 |
| 化学 | `data/chem.js` の資料選択（大学入試の印があるもの。グラフ・構造式・周期表の図つきも出る）を、正解 + まちがい1つ（毎回ランダム）の二択に変換 | 約510 |

- **書式**: `id|大学入試(1基礎 2標準 3発展)|問題文|正解|まちがい|解説(省略可)`。**正解を先に書く**（左右は、出題のたびにランダムに決める）。化学式・数式は `[[H2SO4]]` `[[v^2 = v0^2 + 2ax]]` のように `[[ ]]` で囲むと、添え字・上つきで表示される。英語は、「〜は？」の指示と英文を、画面で分けて表示する。
- **変換の除外**: 「いずれも・どれも・上の〜」を含む選択肢や、「〜でないもの」を問う問題は、二択にしない（他の選択肢に左右されるため）。
- **作りかた**: `node tools/build-duo.mjs` が `data/duo.js` を作る（直接編集しない）。形式・重複・`[[ ]]` の対応・正解とまちがいが同じでないか、を検査する。
- **品質**: 書いたあとに、事実・文法を1問ずつ確認し、答えが2つ考えられるもの（例: 前置詞が2通り使える、など）は除いた。

## 構成
| ファイル | 役割 |
|---|---|
| `js/games/duo/core.js` | 進行（二択・得点・サバイバル・離脱）。ひとり用と部屋で共通 |
| `js/games/duo/questions.js` | 4科目の出題。化学・地理の4択を二択に変換。難しさ・科目・使った問題を避ける |
| `js/games/duo/scene3d.js` | 3D（Three.js r128, `js/vendor/three.min.js`, MIT）。トロッコ・分かれ道・パネル・破片・カメラ |
| `js/games/duo/board.js` | 対戦画面（問題・選択ボタン・3D・得点・答え合わせ）。ひとり用と友達対戦で共通 |
| `js/games/duo/game.js` `store.js` | メニュー・ひとり用・記録 |
| `js/games/duo/online.js` | 友達対戦の画面（部屋・QR・ロビーは `shiritori/online.js` と共通） |
| `worker/duo-room.mjs` | 部屋の進行（サーバー）。正解(priv)は端末に送らない |
| `css/duo.css` | スタイル（そのほかは `geo-*` を共用） |

- 3D は、ゲームを始めるときだけ読み込む（約600KB）。データも、選んだ科目の分だけ読み込む。
- 参考にした、テレビ番組のトロッコ企画の画像・名前・ロゴは使っていない。見た目・演出はすべて自作。

## 3D の作り・省電力
- 低ポリゴン・影なし・画素密度 1.75 まで。描画は、動きのある間（問題の間と答え合わせ）だけで、40fps まで。開始前・答え合わせ後は止まる。
- 画面を離れている間は、ひとり用の時間を止める。
- 3D のパネルの文字は見た目用（全文は、画面のボタンに出る）。

## 友達対戦
`POST /room/new?game=duo` で部屋を作る。ホストがモード・科目・難しさを選び、2〜4人で開始。出題・採点・時間はサーバーが持ち、端末へは問題・制限時間・（締め切り後の）正解だけを送る。他の人の選択は、答え合わせまで見えない（誰が答えたかだけ見える）。抜けた人の分は待たず、残りが全員答えたらすぐ答え合わせ（`docs/multiplayer.md`）。
